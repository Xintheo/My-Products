## 一、方法判定

**主方法**：虚拟基因敲除因果网络扰动模拟（in silico gene knockout via causal network perturbation） **大分类 / 中分类**：1-生物信息学 / 转录组数据分析 -待审 **判定依据**：典型输入数据为"表达矩阵（样本×基因）+ 表型标签"，脚本核心操作链是「特征选择 → WGCNA 找 hub 模块 → GENIE3 推断因果网络 → DPI 剪枝 → 虚拟敲除模拟 → 表型逆转预测」。这不是任何单一经典方法，而是一套自定义的组合工作流，核心语义是"在推断出的调控网络上模拟敲除某基因、预测其级联表型效应"。

**次方法**：

- WGCNA hub 模块识别（`identify_hub_modules`）— 加权基因共表达网络分析
- GENIE3 基因调控网络推断（`infer_causal_network`）
- DPI 网络剪枝（数据处理不等式，`prune_network_dpi_fast`）— ARACNE 类算法
- 差异表达分析（附加环节的 t 检验 + log2FC）
- GO/KEGG 富集分析（`run_vk_enrichment` + clusterProfiler）

## 二、方法学审查（以上述方法的原理为基准）

由于核心算法封装在包内且无源码，以下审查聚焦**驱动脚本可见层**的数据流向、维度方向、尺度假设。

### 【错误】0 项

无。就驱动脚本可见的逻辑而言，未发现可确证的方法学错误。多个可疑点因依赖不可见的包内实现，归入【存疑】。

### 【存疑 / 需验证】5 项

#### 存疑1：矩阵方向（样本×基因 vs 基因×样本）在全链路中反复切换，正确性完全依赖各包函数的内部约定

- **位置**：`focus_mat <- sub_expr[, top_100_hubs]`（列为基因）→ 喂给 `infer_causal_network`（注释称内部会转置）→ 后面 `predict_ko_phenotype` 又显式 `t()`。
- **疑点**：脚本中至少三处对矩阵方向做了不同假设：`select_advanced_features` 输出、GENIE3 输入、AI 预测输入。注释"内部会自动转置""AI预测要求行=基因列=样本"说明方向约定不统一、靠人工记忆维持。任一处方向假设与实际不符，会导致基因-基因关系被静默转置、结果完全错误但不报错。
- **如何验证**：在每个关键函数前后 `print(dim())` 与 `head(rownames()/colnames())`，逐段确认基因究竟在行还是列；核对各函数文档对输入方向的要求。

#### 存疑2：WGCNA 的 trait 用 `as.numeric(as.factor(pheno_vector))` 编码，映射方向不可控

- **位置**：`trait_num <- as.numeric(as.factor(pheno_vector))`。
- **疑点**：`as.factor` 按字母序分配水平，"Tumor"/"Normal" 会被编成 1/2 还是 2/1 取决于字母序，模块-性状相关的**符号**因此依赖偶然。若下游只按相关绝对值取 hub 尚可，但若区分正负相关则方向可能反。
- **如何验证**：检查 `identify_hub_modules` 是否只用 |correlation|；明确指定哑变量编码（如 `Tumor=1, Normal=0`）而非依赖 factor 自动排序。

#### 存疑3：伪计数 log2FC 的 offset 与数据尺度是否匹配未知

- **位置**：附加环节 `real_log2fc <- log2((mean_tumor + 0.1)/(mean_normal + 0.1))` 及虚拟 `log2fc <- log2((ko_mean+0.1)/(wt_mean+0.1))`。
- **疑点**：`+0.1` 伪计数是否合适，完全取决于 `expr_matrix` 的尺度。若数据已是 log 空间，则再对均值做比值取 log2 在方法学上是错的（log 数据不应再当线性值算 FC）；若是线性 counts/TPM，0.1 offset 对低表达基因影响可能过大。
- **如何验证**：确认 `tcga_stad_mini$expr_matrix` 是 counts / TPM / 已 log；据此决定 FC 该如何算、offset 取多少。

#### 存疑4：虚拟 DEG 阈值 `abs(log2fc) > 0.05` 极低，可能纳入大量噪声

- **位置**：`virtual_degs <- names(log2fc)[abs(log2fc) > 0.05]`。
- **疑点**：log2FC 0.05 对应约 3.5% 的表达变化，远低于常规 DEG 阈值（通常 |log2FC|>1）。作为"级联受影响基因"的筛选这可能是有意为之（捕捉微弱传播信号），但也可能让富集分析输入充满噪声。是设计选择还是失误，需作者确认。
- **如何验证**：查看 `log2fc` 分布，确认 0.05 是否能区分真实级联信号与数值噪声；与作者确认该阈值语义。

#### 存疑5：富集分析被重复调用两次，第一次结果被覆盖

- **位置**：GO 富集先在 `if (length(virtual_degs) > 0)` 块内跑了一次 `run_vk_enrichment(..., species="human")`（无 database 参数），随后又在块外重新 `go_res <- run_vk_enrichment(virtual_degs, species="human", database="GO")` 跑一次。
- **疑点**：这更像工程冗余而非方法学错误——第一段的 `go_res`/`p3` 被第二段完全覆盖，且第二段不受 `length(virtual_degs)>0` 保护，若 `virtual_degs` 为空会直接把空向量传入富集函数。
- **如何验证**：确认是否有意保留两段；合并为一次调用并统一置于长度检查内。

### 【正确】3 项（易被误判为错误的地方）

#### 正确1：`sub_expr[, top_100_hubs, drop = FALSE]` 显式保留矩阵格式

- **位置**：`focus_mat <- as.matrix(sub_expr[, top_100_hubs, drop = FALSE])`。
- **为什么是对的**：`drop=FALSE` 防止单列时矩阵退化为向量，是正确的防御性写法，不应被"改简洁"删掉。

#### 正确2：`predict_ko_phenotype` 前的 `t()` 转置是刻意的，不是多余

- **位置**：`WT_matrix = t(ko_results$WT)`。
- **为什么是对的**：注释已说明该函数要求"行=基因、列=样本"，而 `ko_results$WT` 是样本×基因，故转置是满足接口要求的必要操作，非冗余。

#### 正确3：t 检验外包 `tryCatch(..., error=function(e) 1)` 处理零方差基因

- **位置**：附加环节批量 `real_pvals` 计算。
- **为什么是对的**：某基因在一组内方差为 0 会使 `t.test` 报错中断整批；捕获后返回 p=1（即"不显著"）是合理兜底，不是掩盖问题。

## 四、改进后的脚本

应用了：魔数集中到参数设置区、矩阵方向约定集中声明并加维度断言、富集调用统一加非空与包检查、去除重复富集调用。**未改动**任何包内函数的调用语义与已确认正确的 `drop=FALSE`/`t()` 转置。

```r
# =====================================================================
# bulkKnk 全链路试飞脚本 (run_test.R)
# 用法：改好"参数设置区"后直接 source 运行；依次产出敲除 delta 图、
#       双重火山图、GO/KEGG 富集气泡图
# 维度约定（务必牢记）：
#   - expr / sub_expr / focus_mat : 行=样本, 列=基因
#   - infer_causal_network        : 内部自转置，喂 样本×基因 即可
#   - predict_ko_phenotype        : 要求 行=基因,列=样本 → 传入前 t()
# =====================================================================

# ---- 依赖包检查与加载 ----
.need <- c("devtools", "clusterProfiler")
for (p in .need) {
  if (!requireNamespace(p, quietly = TRUE))
    stop(sprintf("缺少依赖包：%s，请先安装", p))
}
devtools::load_all()
data("tcga_stad_mini")

# =====================================================================
# 参数设置区 —— 只需修改这里
# =====================================================================
N_FEATURES      <- 500        # 初筛核心特征数
N_HUBS          <- 100        # 送入网络推断的 hub 基因上限（过大易卡死）
DPI_THRESHOLD   <- 0.5        # DPI 剪枝阈值
KO_METHOD       <- "shift"    # 虚拟敲除方式
TARGET_GROUP    <- "Tumor"    # 关注的表型组
PHENO_FIELD     <- "SampleType"  # 表型字段名
PSEUDOCOUNT     <- 0.1        # log2FC 伪计数（须与数据尺度匹配，见存疑3）
VIRTUAL_DEG_CUT <- 0.05       # 级联 DEG 的 |log2FC| 阈值（偏低，见存疑4）
ENRICH_SPECIES  <- "human"    # 富集物种
# =====================================================================

pheno_vector <- tcga_stad_mini$pheno_data[[PHENO_FIELD]]

message("\n========================================================")
message("🚀 启动 bulkKnk 全链路试飞")
message("========================================================\n")

# =====================================================================
# 步骤1：特征提取与靶点发现（特征选择 → WGCNA hub 模块）
# =====================================================================
sub_expr <- select_advanced_features(tcga_stad_mini$expr_matrix, n_features = N_FEATURES)

trait_num <- as.numeric(as.factor(pheno_vector))
wgcna_res <- identify_hub_modules(sub_expr, trait_vec = trait_num)

top_hubs   <- head(wgcna_res$best_genes, N_HUBS)
top_target <- top_hubs[1]
message(sprintf(">>> [决策] 即将敲除的靶点是: %s", top_target))

# =====================================================================
# 步骤2：构建因果网络（GENIE3 推断 → DPI 剪枝 → 归一化）
# =====================================================================
focus_mat <- as.matrix(sub_expr[, top_hubs, drop = FALSE])   # 行=样本,列=基因
stopifnot(ncol(focus_mat) == length(top_hubs))

net_raw   <- infer_causal_network(focus_mat)                 # 内部自转置
net_clean <- prune_network_dpi_fast(net_raw$clean_matrix, dpi_threshold = DPI_THRESHOLD)

# 强制贴回基因名，防止网络推断过程丢名
rownames(net_clean) <- colnames(focus_mat)
colnames(net_clean) <- colnames(focus_mat)

W_norm <- sweep(t(net_clean), 2, colSums(t(net_clean)) + 1e-9, FUN = "/")

# =====================================================================
# 步骤3：虚拟敲除模拟
# =====================================================================
ko_results <- batch_virtual_knockout(
  expr_matrix  = focus_mat,
  pheno_vec    = pheno_vector,
  target_pheno = TARGET_GROUP,
  target_genes = top_target,
  adj_matrix   = W_norm,
  method       = KO_METHOD
)

# =====================================================================
# 步骤4：AI 表型逆转预测（predict 要求 行=基因,列=样本 → t()）
# =====================================================================
baseline_labels <- ifelse(
  ko_results$WT[, top_target] > median(ko_results$WT[, top_target]),
  "HighRisk", "LowRisk"
)

report <- predict_ko_phenotype(
  WT_matrix    = t(ko_results$WT),
  KO_matrix    = t(ko_results$KO),
  pheno_labels = baseline_labels,
  target_pheno = "HighRisk",
  ko_gene      = top_target
)

p <- plot_ko_delta(report, color_by = "direction")
print(p)

# =====================================================================
# 步骤5：真实临床差异（Tumor vs Normal）作为对照
# =====================================================================
message("   > 计算真实临床队列 T 检验 P 值与 Log2FC...")
is_tumor    <- pheno_vector == TARGET_GROUP
expr_tumor  <- sub_expr[is_tumor, , drop = FALSE]
expr_normal <- sub_expr[!is_tumor, , drop = FALSE]

mean_tumor  <- colMeans(expr_tumor)
mean_normal <- colMeans(expr_normal)
real_log2fc <- log2((mean_tumor + PSEUDOCOUNT) / (mean_normal + PSEUDOCOUNT))

real_pvals <- sapply(seq_len(ncol(sub_expr)), function(i) {
  tryCatch(t.test(expr_tumor[, i], expr_normal[, i])$p.value,
           error = function(e) 1)
})

my_real_deg <- data.frame(
  Gene   = colnames(sub_expr),
  log2FC = real_log2fc,
  pvalue = real_pvals
)

# =====================================================================
# 步骤6：双重火山图
# =====================================================================
p2_dual <- plot_dual_volcano(
  real_deg_df  = my_real_deg,
  WT_matrix    = ko_results$WT,
  KO_matrix    = ko_results$KO,
  target_genes = top_target
)
print(p2_dual)

# =====================================================================
# 步骤7：级联 DEG 提取 → GO / KEGG 富集
# =====================================================================
message("\n--- 运行级联反应富集分析 ---")
wt_mean <- colMeans(ko_results$WT)
ko_mean <- colMeans(ko_results$KO)
log2fc  <- log2((ko_mean + PSEUDOCOUNT) / (wt_mean + PSEUDOCOUNT))

virtual_degs <- names(log2fc)[abs(log2fc) > VIRTUAL_DEG_CUT]
virtual_degs <- setdiff(virtual_degs, top_target)

if (length(virtual_degs) > 0) {
  message(sprintf(">>> [Enrichment] %d 个级联受影响基因，启动富集...", length(virtual_degs)))

  # GO
  go_res <- run_vk_enrichment(virtual_degs, species = ENRICH_SPECIES, database = "GO")
  if (!is.null(go_res) && nrow(go_res) > 0) {
    print(clusterProfiler::dotplot(
      go_res, showCategory = 10,
      title = paste("GO Pathways Shifted after", top_target, "KO")))
  }

  # KEGG
  kegg_res <- run_vk_enrichment(virtual_degs, species = ENRICH_SPECIES, database = "KEGG")
  if (!is.null(kegg_res) && nrow(kegg_res) > 0) {
    print(clusterProfiler::dotplot(
      kegg_res, showCategory = 10,
      title = paste("KEGG Signaling after", top_target, "KO")))
  }
} else {
  message(">>> [Enrichment] 该靶点敲除未引起广泛级联反应，跳过富集分析。")
}
```
